## 🚀 Featured Projects

### [careOS — Clinic & Hospital Management Platform](https://github.com/ciperrax/careos)
A production-grade, multi-tenant clinic and hospital management platform built for the Kenyan healthcare market — covering the entire patient journey from registration to billing.

- **Backend:** Modular-monolith NestJS/Fastify API in TypeScript, with PostgreSQL, Prisma, Redis, and BullMQ
- **Architecture:** Row-level multi-tenancy with Postgres RLS, an outbox-pattern event system, strong RBAC, and full auditability
- **Clinical coverage:** Registration, scheduling, queueing, triage, clinical encounters, laboratory, pharmacy with FEFO inventory, inpatient/bed management, billing with a double-entry ledger, M-Pesa payments, and insurance claims
- **Frontend:** Next.js 15 (Tailwind v4, TanStack Query/Table, Zod, re-skinned Radix components) in a "Clinical Editorial" design language, with dense, worklist-first workspaces per role — reception, nursing, doctor, lab, pharmacy, billing, admin — plus a mobile-first patient portal and a waiting-room queue display
- **Public layer:** A hospital-finder landing page (geolocation with manual fallback) and an emergency-help request flow that alerts opted-in facilities — without claiming to dispatch or triage — backed by a cross-tenant-safe, PostGIS-powered public API

> Deliberately scoped as an operations/information system, not a diagnostic one.
